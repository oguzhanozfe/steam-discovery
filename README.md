# Steam Discovery

Steam Discovery is a research and decision-support site for indie PC game teams. It combines market signals, case studies, genre demand, and an execution-ready three-week survival-demo plan.

Live site: [steam-discovery.vercel.app](https://steam-discovery.vercel.app/)

## Local development

Requirements: Node.js 22.13 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build:vercel
```

Local environment files, generated output, and Vercel project metadata are excluded from version control.
